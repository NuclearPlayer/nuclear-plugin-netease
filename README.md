# NetEase Cloud Music plugin for Nuclear

Streaming and metadata provider for [NetEase Cloud Music](https://music.163.com/) (网易云音乐). No account required.

The plugin automatically filters out all paid tracks. Unfortunately, that causes some albums to be empty, because there is no way to filter albums before looking at their details.

## Installation

Install from the Nuclear plugin browser.
